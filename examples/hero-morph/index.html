About this experiment & running it locally

This is a first-milestone fitting room, not a full game. There is no inventory, save data, title menu, sound, or online service. The character and illustrations are original procedural assets. No external fonts or images are fetched.

From examples/hero-morph: run npm ci, then npm run dev. Run npm test for pure state and geometry tests and npm run build for the production bundle. Use npm run preview to preview that build. Node 22.18 or newer is required.

Browser checks: install the repository-root dependencies with npm ci at the root, then install its pinned browser with node node_modules/@playwright/test/cli.js install chromium. Back in this example, run npm run test:browser. This intentionally uses the root Playwright and axe packages; no separate browser-test dependencies are added here.

Tests cover real WebGL rendering, geometry and attachments, interaction, reduced motion in the renderer, static fallback, and lifecycle behavior. Candidate desktop and mobile screenshots live in this example’s ignored test-results. They are evidence, not approved visual baselines. GPU appearance across physical devices and assistive-technology reading still need human review.

Your operating system’s reduced-motion preference makes shape changes immediate. The renderer stops when still, hidden, or offscreen. If 3D is unavailable, the two illustrated forms remain usable. Context restoration retries 3D automatically; reload if recovery fails.

Reusable exports: src/state.ts (equipment and transitions), src/shape.ts (geometry and attachment math), and src/assets.ts (Three.js factory). See the asset contract for topology, provenance, rights, and limits. This example is separate from Etcha’s adoption payload.
