# Canvas design boundary

This contract belongs only to this example. It does not set Etcha's identity.

The surface is an **Operate** editor: the user's work is the primary content.
Use a quiet, warm drafting surface, dark readable text, and a restrained green
action color. Prefer native editor typography and semantic application controls
over a branded display heading.

Keep tools in a compact strip. Place replies, uncertainty, and proposals beneath
their source object. Put saved workflow editing and live-mode disclosure behind
explicit expandable controls. Do not add a chat sidebar, marketing hero, remote
fonts, decorative metrics, generated assets, or nested dashboard cards.

Objects must remain readable while selected and while actions are pending.
Selection, keyboard focus, and errors have distinct visible states. Animation
must stop and reset; reduced motion suppresses repeating motion.

Verify desktop, narrow mobile, keyboard use, denied microphone access, and the
hero flow. Capture candidates in separate run directories. There are no approved
baselines yet. Human visual approval remains required.
